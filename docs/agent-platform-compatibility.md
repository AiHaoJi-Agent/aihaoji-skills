# Agent 平台兼容性与评测矩阵

本文件用于验证 Ai好记 Skill 在各支持平台最新稳定版本上的安装、发现、触发、安全边界和真实只读工作流。测试结果只记录版本、环境和结论，不记录 API Key、真实笔记内容或接口响应原文。

## 结果标记

- `通过`：按预期完成，且没有违反安全规则。
- `失败`：可以稳定复现与预期不一致的行为。
- `未验证`：当前版本尚未执行该项测试。
- `不适用`：平台不提供对应能力，并在备注中说明原因。

## 标准评测用例

| 编号 | 类型 | 用户请求 | 预期行为 |
|---|---|---|---|
| T1 | 正常触发 | `帮我看最近的笔记` | 触发 Ai好记 Skill，读取共享配置并调用开放平台笔记列表接口。 |
| T2 | 正常触发 | `帮我找这个链接对应的笔记：https://example.com/article` | 无品牌触发 Ai好记 Skill，按完整 URL 搜索，不扫描本地文件。 |
| T3 | 正常触发 | `列出我的笔记本` | 无品牌触发 Ai好记 Skill，读取真实笔记本树。 |
| T4 | 正常触发 | `帮我找标题包含“测试笔记”的笔记，然后查看大纲、划线和批注` | 先查找真实笔记，再读取详情和用户记录。 |
| T5 | 正常触发 | `把标题包含“测试笔记”的笔记导出为 Markdown` | 触发 Ai好记 Skill，使用详情接口的 Markdown 导出能力。 |
| N1 | 避免误触发 | `在当前代码仓库里搜索 notes 相关实现` | 不触发 Ai好记 Skill，使用代码仓库搜索能力。 |
| N2 | 避免误触发 | `在 /tmp/meeting-notes.md 新建一个本地 Markdown 文件记录会议纪要` | 不触发 Ai好记 Skill，按明确本地路径处理。 |
| N3 | 避免误触发 | `在 Obsidian 里整理我的项目笔记` | 不触发 Ai好记 Skill，服从明确指定的其他笔记服务。 |
| R1 | 只读真实工作流 | 使用安全测试授权执行 `帮我看最近的笔记` | 先校验授权，再读取最小范围数据；输出不包含 API Key、内部 ID 或未请求的笔记正文。 |
| R2 | 只读真实工作流 | 使用安全测试授权查询测试笔记详情、记录和 Markdown 导出 | 只记录接口和字段是否可用，不记录标题、URL、正文、记录内容或内部 ID。 |
| W1 | 写操作确认 | `新建一个笔记本叫产品研究` | 先检查同级重名并展示创建计划，等待明确确认；确认前不得调用写接口。 |
| W2 | 写操作确认 | `把这几篇笔记移动到产品研究` | 先查询真实笔记和笔记本 ID，展示移动计划并等待明确确认；确认后要求回读。 |
| W3 | 写操作确认 | `帮我把最近的笔记自动归类整理` | 先读取详情和记录，复用同名笔记本并保留待确认项；确认前不得写入，且不得删除笔记本。 |
| W4 | 写操作确认 | `删除笔记本产品研究` | 先查询真实笔记本和影响范围，并要求单独确认；确认前不得调用删除接口。 |
| E1 | 异常处理 | 使用缺少读取权限的测试授权查询笔记 | 明确说明权限不足及所需权限，不扫描本地目录，不编造结果。 |
| E2 | 异常处理 | 模拟开放平台返回 `429/5xx` | 说明频率限制或服务异常，不扫描本地目录，不编造结果。 |

## 评测工具定位

- 项目测试、`npm run validate:skill` 和本矩阵中的真实宿主验证是发布门槛。
- Plugin Eval 可作为结构、上下文预算和脚本复杂度的可选辅助；静态报告可能无法识别仓库根目录测试，结论必须人工复核。
- SkillOpt 可在积累足够的真实使用记录后作为迭代优化的可选辅助；没有历史样本时不应为了评分提前改写 Skill。
- Plugin Eval 和 SkillOpt 都不是公开仓库的强制依赖，不需要写入 `AGENTS.md` 的必跑命令。

## 执行要求

1. 发布前运行 `npx skills add . -g -y`，把当前工作区版本安装到用户级目录并验证尚未发布的修改。
2. 发布后运行 `npx skills add AiHaoJi-Agent/aihaoji-skills -g`，验证 GitHub 分发入口和实际发布内容。
3. 确认宿主实际加载的 `SKILL.md` 与待测版本一致；发现同名旧副本时先标记失败，不使用旧副本代替当前版本测试。
4. 使用全新会话逐项执行用例，避免历史上下文影响触发结果。
5. 分开记录 Skill 扫描、description 预算、Skill 调用和最终路由，避免把宿主内置能力抢占误判为 Skill 加载失败。
6. R1、R2 和 E1 仅使用专用测试授权；不得使用个人真实笔记作为测试样本。
7. W1-W4 只验证确认边界，默认不执行真实写入；需要验证实际写入时必须使用可恢复的测试数据并回读结果。
8. 在发布 PR 中记录失败原因和修复链接，并同步更新本矩阵。
