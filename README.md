## 关于 Ai好记

[Ai好记](https://aihaoji.com) 是一款专业的 **AI音视频总结、视频转文字与多模态知识管理工具**，帮助用户把视频、音频、课程、播客和会议内容快速整理成可阅读、可搜索、可继续学习和长期沉淀的知识。

支持B站、抖音、小红书、小宇宙等在线视频链接直接解析，也可导入本地音视频和网盘文件进行转录与整理；一键完成视频转文字、AI视频总结、多语言翻译、PPT提取和视频转图文，自动生成结构化要点和多级思维导图，同时支持AI问答、多格式导出，并同步到Notion、Obsidian。适用于网课学习、播客整理、会议纪要等多种场景。

### 主要功能

- **多来源音视频导入**：支持B站、抖音、小红书、小宇宙等在线视频链接直接解析，也支持本地音视频、百度网盘、阿里云盘和录音内容导入，可批量处理长视频、课程和播客。

- **音视频转文字**：自动将视频、音频、课程、播客和会议转成完整逐字稿，保留时间戳和发言人信息，方便搜索、阅读和回看原内容。

- **AI润色文稿**：在保留原始逐字稿的基础上，对口语表达、断句和专业术语进行优化，让转录内容更准确、更易读。

- **AI视频总结**：自动提炼内容概览、关键词、章节、核心要点、问答总结和术语解释，支持学习、会议、创作等多种总结模板，也可以使用自定义 Prompt。

- **AI视频转图文**：自动提取视频中的PPT、图表和关键画面，与对应逐字稿一起生成图文笔记，让长视频不只是转成文字，也能保留重要的视觉信息。

- **AI精华速览**：从长视频、网课、播客和会议中快速提取核心内容，先看精华，再决定哪些部分值得继续深入。

- **AI思维导图**：根据内容自动生成结构化大纲和多级思维导图，把长视频、课程和会议整理成清晰的知识框架。

- **多语言翻译**：支持中、英、日、韩等22种语言双语翻译，原文与译文可对照查看，适合外语课程、海外视频、播客和访谈内容。

- **AI对话问答**：围绕单篇笔记随时提问，支持知识点解释、重点总结、内容梳理和练习出题，并内置多种学习模板。

- **AI助理**：支持调用多篇笔记和多个笔记本进行跨内容搜索、总结、对比和问答，并可查看引用来源，用已有知识继续学习、研究和内容二创。

- **高亮划线与批注**：阅读笔记时可以高亮、划线、添加批注和随时记录自己的想法，把AI整理的内容和个人理解放在一起。

- **空白笔记**：除了AI生成的音视频笔记，也可以自己创建和编辑文字笔记，把灵感、总结和个人记录与已有音视频知识一起管理。

- **AI播客**：可以把已有内容生成双人对话式AI播客，把原本需要阅读的知识转换成可以继续听的内容。

- **AI知识库**：统一管理视频、播客、课程、会议和个人笔记，支持多级分类、全局搜索、笔记本管理与分享，并可通过AI助理调用多篇笔记和多个笔记本中的知识，让零散内容逐步沉淀成个人知识库。

- **多格式导出**：支持Word、PDF、Markdown、XMind、HTML等格式导出，也可以同步或导入Notion、Obsidian，继续进入已有的学习和知识管理工作流。

Ai好记 Skill 让 Codex、OpenClaw、Claude Code、Hermes Agent 等兼容 Agent Skills 的平台连接你的 Ai好记知识库，
在聊天中查找、阅读、导出和整理笔记，并管理笔记本。

## 适用场景

- `帮我看最近的笔记`
- `帮我找Ai好记相关的内容`
- `帮我找这个 URL 对应的笔记：https://www.bilibili.com/video/BV...`
- `帮我看这篇笔记的总结、原文或大纲`
- `帮我读取这篇笔记的划线和批注`
- `新建一个笔记本叫产品研究`
- `帮我创建一篇笔记，标题是会议结论，正文是：## 结论 ...`
- `把这几篇笔记移动到产品研究`
- `帮我把 2026年7月2日 的笔记自动归类整理`

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 查找笔记 | 查看最近笔记，或按关键词、标题、时间、笔记本和原始 URL 查找已有笔记 |
| 按链接找笔记 | 使用原始内容 URL 定位对应的 Ai好记笔记 |
| 阅读详情 | 查看总结、大纲、精华速览、润色稿、原文和完整内容 |
| 导出 Markdown | 使用详情接口返回的 Markdown 内容导出单篇笔记 |
| 创建空白笔记 | 使用 Markdown 创建正式空白笔记，可选指定笔记本，创建后回读验证 |
| 读取用户记录 | 查看划线、高亮、批注和我的记录，作为阅读和整理依据 |
| 管理笔记本 | 新建、重命名、删除和移动笔记本，写入前先展示操作计划 |
| 移动整理笔记 | 把单篇或多篇笔记移动到指定笔记本，并回读验证结果 |
| 自动归类整理 | 读取笔记和用户记录，生成归类计划，经确认后创建笔记本并移动笔记 |

## 安装

安装 Skill，让不同 Agent 平台都可以使用：

```bash
npx skills add AiHaoJi-Agent/aihaoji-skills -g
```

`-g` 表示为当前用户安装。此命令会安装到检测到的兼容 Agent，无需逐个平台重复安装。

## 配置 API Key

首次使用时，直接告诉 Agent 你想查找或整理哪些笔记。若尚未配置 API Key，Agent 会引导你完成：

1. 前往 [Ai好记开放平台](https://aihaoji.com/skill) 创建开发者密钥。
2. 按照当前 Agent 的提示完成授权。
3. 当前 Agent 会在你授权后完成校验并保存到当前电脑，然后继续处理刚才的请求。

同一台电脑上的 Codex、OpenClaw、Claude Code 和 Hermes Agent 可以共用一次配置，无需在不同 Agent 中重复配置。

请妥善保管 API Key，不要公开分享。
